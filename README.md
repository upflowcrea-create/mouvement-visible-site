# Mouvement Visible — site vitrine

Site statique (HTML, CSS, JS) de Mouvement Visible, agence web pour les enseignants en APA.

- `index.html` : page d'accueil
- `mentions-legales.html`, `cgv.html` : pages légales
- `merci.html` : page affichée après l'envoi du formulaire
- `assets/` : styles, script, images

Hébergement : Netlify, déployé automatiquement depuis la branche `main`.
Le formulaire de contact utilise Netlify Forms (les messages arrivent dans le tableau de bord Netlify, rubrique Forms).
